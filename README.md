# 诗词格律 · 古代汉语学习路径

一个**基于古代汉语知识库原文**制作的**可交互学习路径**网页：从「什么是诗韵」讲到「词牌与词韵」，20 个节点层层递进，配上点字看平仄、80 道自测题与 143 条原著引用，让你像玩游戏一样把诗词格律学透。

> 🌐 **在线体验**：[打开学习路径](https://yu-403.github.io/poetry-meter-learning-path/)（无需安装，浏览器直接使用）
>
> 📄 **单文件版直达**：[诗词格律学习路径.html](https://github.com/YU-403/poetry-meter-learning-path/blob/main/%E8%AF%97%E8%AF%8D%E6%A0%BC%E5%BE%8B%E5%AD%A6%E4%B9%A0%E8%B7%AF%E5%BE%84.html)（可下载后双击即用）

> 期末复习《古代汉语》的诗词格律，对着课本翻来翻去记不住？这个网页把王力《诗词格律》系列 + 喻守真《唐诗三百首详析》里的核心知识，拆成了一条 20 步的学习路径——每步先讲概念、再看规则、配例句、避误区，最后做题检验。

## ✨ 功能亮点

| 功能 | 说明 |
|---|---|
| 🗺️ **20 节点学习路径** | 概念·诗韵(11) → 诗体·近体(6) → 词·词牌与词韵(3)，层层递进，**可自由跳关** |
| 📖 **五段式内容** | 每个节点按「目标 / 概念讲解 / 规则表 / 例句 / 常见误区」组织，最后接自测 |
| 📜 **143 条原著引用** | 讲解中嵌入王力《诗词格律》《诗词格律十讲》、王力主编《古代汉语》、喻守真《唐诗三百首详析》原文，逐字可溯源、**标出处**；含 **cite 行内引用** 与 **compare 双栏对比**（同一概念两种讲法） |
| 🎯 **语义化强调** | 按语义标注三档：**朱砂加粗**（最强重点）/ **金赭变色**（术语概念）/ **朱砂下划线**（易错呼应），非机械加粗 |

| 📐 **排版统一** | 律诗绝句按「一联一行」；词按「上下阕」连排，阕内句子连排 |
| 🔄 **平仄标注模式** | 汉字「平/仄」 ↔ 符号「○/●」一键切换 |
| 💾 **进度与续读** | 全局 + 分板块 + 节点内续读 + **重置进度**，浏览器本地保存（localStorage） |
| 📑 **速查表** | 平水韵 106 韵、绝句平仄格式、入声字 17 韵、邻韵通用、词林正韵、对仗分类、例诗库 |

## 🛠️ 二次开发

```bash
# 重新打包单文件版（改完代码后执行，输出覆盖「诗词格律学习路径.html」）
python build.py

# 重新生成内容数据 data.js（改数据源后执行）
python data/build_data.py
```

- **改内容**：编辑 `data/nodes/*.json` 后重跑 `data/build_data.py`，或直接改 `data/data.js`。
- **语义强调标记**：讲解文本中可用 `**词**`（朱砂加粗）、`==词==`（金赭变色）、`__词__`（朱砂下划线）三层标记按语义强调。
- **改样式**：直接编辑 `css/style.css`，配色变量在文件顶部 `:root`。
- **改交互**：直接编辑 `js/app.js`。

## 📚 数据来源与准确性

- 全部内容**严格来自本地 Alpha-RAG「古代汉语」知识库**原文——王力《诗词格律》《诗词格律十讲》《诗词格律概要》、王力主编《古代汉语》、喻守真《唐诗三百首详析》及董文焕《声调四谱图说》、赵执信《声调谱》等，**未引入库外内容**。
- **143 条引用全部经 RAG 溯源复查**，逐字可在知识库原文中找到对应。
- 例诗逐字平仄依据知识库**格式标注 + 入声字提示**或喻守真逐字 ○● 标注推导；知识库未标注处**不强行补注**。
- 速查表（106 韵、入声字表等）按知识库原文完整收录。
