# 诗词格律 · 古代汉语学习路径

一个**基于古代汉语知识库原文**制作的**可交互学习路径**网页：从「什么是诗韵」讲到「词牌与词韵」，20 个节点层层递进，配上点字看平仄、80 道自测题，让你像玩游戏一样把诗词格律学透。

> 🌐 **在线体验**：[打开学习路径](https://yu-403.github.io/poetry-meter-learning-path/)（无需安装，浏览器直接使用）

> 期末复习《古代汉语》的诗词格律，对着课本翻来翻去记不住？这个网页把王力《诗词格律》系列 + 喻守真《唐诗三百首详析》里的核心知识，拆成了一条 20 步的学习路径——每步先讲概念、再看规则、配例句、避误区，最后做题检验。

---

## ✨ 功能亮点

| 功能 | 说明 |
|---|---|
| 🗺️ **20 节点学习路径** | 概念·诗韵(11) → 诗体·近体(6) → 词·词牌与词韵(3)，层层递进，**可自由跳关** |
| 📖 **五段式内容** | 每个节点按「目标 / 概念讲解 / 规则表 / 例句 / 常见误区」组织，最后接自测 |
| ✅ **80 道点击式自测** | 全程**免键盘**作答，答错可**重试一次**，每题必有解析 |
| 🖱️ **点字看平仄** | 例诗**逐字可点**：浮层显示平仄 + 整句联动着色；节点例诗韵脚可看拼音 |
| 🔄 **平仄标注模式** | 汉字「平/仄」 ↔ 符号「○/●」一键切换，两种视角对照理解 |
| 💾 **进度与续读** | 全局 + 分板块 + 节点内续读，浏览器本地保存（localStorage），刷新不丢 |
| 📑 **速查表** | 平水韵 106 韵、绝句平仄格式、入声字 17 韵、邻韵十五类、词林正韵、对仗分类 |

## 🏗️ 项目结构

```
诗词格律学习路径/
├── index.html                页面骨架（开发版入口）
├── 诗词格律学习路径.html      单文件版（build.py 打包产物，发人用）
├── build.py                  打包脚本：内联 CSS/JS/数据 → 生成单文件版
├── README.md                 本说明
├── css/
│   └── style.css             全部样式与动效（古典书卷风）
├── js/
│   └── app.js                全部交互逻辑
└── data/
    ├── data.js               全部内容数据（20 节点 + 例诗 + 速查表）
    └── build_data.py         重新生成 data.js 的数据构建脚本
```

## 🛠️ 二次开发

```bash
# 重新打包单文件版（改完代码后执行，输出覆盖「诗词格律学习路径.html」）
python build.py

# 重新生成内容数据 data.js（改数据源后执行）
python data/build_data.py
```

- **改内容**：编辑 `data/data.js` 中对应对象，或改 `data/nodes/*.json` 后重跑 `data/build_data.py`。
- **改样式**：直接编辑 `css/style.css`，配色变量在文件顶部 `:root`。
- **改交互**：直接编辑 `js/app.js`。

## 📚 数据来源与准确性

- 全部内容**严格来自本地 Alpha-RAG「古代汉语」知识库**原文——王力《诗词格律》《诗词格律十讲》《诗词格律概要》、喻守真《唐诗三百首详析》及《古代汉语》教材，**未引入库外内容**。
- 例诗逐字平仄依据知识库给出的**格式标注 + 入声字提示**推导；知识库未标注的字**不强行补注**。
- 速查表（106 韵、入声字表等）按知识库原文完整收录。

## 🎨 视觉风格

古典书卷风：**宣纸米 `#F4EFE3`** 底 + **暖墨 `#3A3226`** 字 + **朱砂 `#C0392B`** 点缀 + **黛青 `#4A6741`** 辅助。完成盖章、展卷切换、段落渐显、按钮涟漪等递进动效。

## 💡 说明

- 诗词字体默认使用系统**楷体**（KaiTi）；如需「霞鹜文楷」手写质感，可将 woff2 放入 `assets/fonts/` 并在 `css/style.css` 补 `@font-face`（该字体官方分片发布、体积较大，故未内置）。
- 纯桌面版，建议电脑浏览器打开；数据保存在浏览器本地，清缓存会清空学习进度（可点「重置进度」）。
